Same-origin fallback for How to Use idoc.club recordings (MP4, H.264/AAC). The primary home for the videos is Cloudinary
(`idoc/how-to/<section id>`, see `scripts/how-to-videos/` and `howToVideoUrl` in `lib/how-to/guide.ts`). To use a file here
instead, set the section's `videoSrc` to, for example, `'/how-to-videos/directory.mp4'`.
