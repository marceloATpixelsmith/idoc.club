Place the How to Use idoc.club recordings here as MP4 (H.264/AAC) files, then set `videoSrc` for the matching section in
`lib/how-to/guide.ts`, for example `'/how-to-videos/directory.mp4'`. The site's content security policy allows media only from
the site's own origin, so videos must be served from this folder (or the policy must be extended deliberately).
